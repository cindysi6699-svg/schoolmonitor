# 直資中學中一招生監察

每天早上自動查閱 19 間直資中學（男女校及女校）的網站，判斷 **2027/28 學年中一入學申請** 是否已開放報名。開放時推送 Discord 通知，並更新一個網頁狀態板。

---

## 部署（約 10 分鐘）

**1. 建立 public 倉庫，把這些檔案推上去**

```
schools.yaml                    20 間學校的網址
config.yaml                     年份、關鍵詞、抓取預算
check.py                        主程式
index.html                      狀態板
data/                           結果（由程式自動寫入）
.github/workflows/daily.yml     每日排程
```

**2. 設定 Discord 通知**

倉庫 → Settings → Secrets and variables → Actions → New repository secret

| Name | 值 | 必填 |
|---|---|---|
| `DISCORD_WEBHOOK` | webhook 網址 | 是 |
| `DISCORD_USER_ID` | 你的 Discord 數字 ID | 否，填了才會 @ 你 |

取得 ID：Discord 設定 →「進階」→ 開啟「開發者模式」→ 長按自己頭像 →「複製使用者 ID」。

**切勿把 webhook 寫進任何檔案**，這是 public 倉庫。

**通知規則**：每天固定發一條彙總，內容為各狀態的數量。只有「新開放」和
「需複核」才會 @ 你 —— 天天 @ 的話，真有事那天你反而分辨不出來。

**3. 開啟網頁**

Settings → Pages → Source 選 `Deploy from a branch`，branch 選 `main` / `(root)`。
網址為 `https://<你的帳號>.github.io/<倉庫名>/`。

**4. 先手動跑一次**

Actions → 每日檢查招生狀態 → Run workflow。看 log 有沒有大量 `fetch failed`。

---

## 每天發生什麼

香港時間早上 7 點觸發。對每間學校：

1. 抓首頁，找出最像招生頁的 3–4 條連結（依 href 與連結文字評分，`中一`／`S1` 權重最高，`小一`／`插班`／`招聘` 直接排除）
2. 逐頁檢查，最深 2 層，每校上限 8 頁，請求間隔 1.5 秒
3. 一頁上同時出現 **目標年份 + 中一 + 招生字眼** → 判定為已開放
4. 首次由未開放轉為開放時，推送 Discord

發現到的連結會存進 `data/discovered.json`，隔天直接沿用，不重複發現。

三種狀態：

| 狀態 | 意思 |
|---|---|
| 已開放 | 規則命中 |
| 尚未開放 | 抓取成功但未命中 |
| 需人工確認 | 抓取失敗，或首頁找不到招生連結（多為 JS 導覽） |

**「需人工確認」必須當回事** —— 這代表程式沒看到，不代表學校沒開放。

## 調整

**改年份**：只改 `config.yaml` 的 `target_label` 和 `year_tokens`，明年沿用同一套程式。

**某校誤判或抓不到**：在 `schools.yaml` 給它加一行 `entry:`，直接指定招生頁，跳過自動發現。例如：

```yaml
  - name: 協恩中學
    home: https://www.hys.edu.hk/
    entry: https://www.hys.edu.hk/xxx/admission
```

**改執行時間**：`daily.yml` 的 cron 用 UTC。香港時間減 8 小時。

**學校改版後路徑失效**：刪掉 `data/discovered.json`，下次執行會重新發現。

---

## 已知限制

- **JS 渲染的導覽選單抓不到連結。** 這類學校會落到「需人工確認」。解法是手動補 `entry:`，或改用 Playwright。
- **只認 PDF 檔名，不讀 PDF 內容。** 名為 `S1_Admission_2027-28.pdf` 的連結會命中；內容藏在 PDF 裡而檔名無年份的則不會。
- **部分學校只在 Facebook 公布。** 無法穩定抓取。
- **判定僅供提示。** 報名日期、所需文件、截止時間一律以學校官方公布為準。
